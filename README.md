# Tabloom

Tabloom 是一个 Manifest V3 Chrome 扩展，支持按域名自动整理标签页、修改标签标题，并通过 Side Panel 命名和切换多个任务窗口。

## 功能

### 任务窗口切换器

- 按 `⌘⇧K`（macOS）或 `Ctrl+Shift+K`（Windows/Linux）呼出侧边栏。
- 也可从工具栏弹窗打开侧边栏。
- 侧边栏列出所有普通窗口，显示自定义名称、当前标签域名和标签数。
- 当前窗口高亮，点击任意一条即可聚焦跳转。
- 打开后可用 `↑` / `↓` 循环选择任务窗口，按 `Enter` 跳转并自动关闭侧边栏。
- 双击窗口名称可就地重命名，名称在当前浏览器会话内保存。
- 点击“新建任务窗口”可快速创建新窗口。
- 侧边栏平时完全隐藏（宽度为 0），不占用任何浏览空间。

### 标签标题

- 在工具栏弹窗中设置或恢复当前标签标题。
- 在网页内容区右键选择“重命名当前标签页”。
- 使用 `⌘⇧E` / `Ctrl+Shift+E` 快速重命名。
- 自定义标题以标签实例为单位保存，刷新后仍生效，关闭标签后自动清理。

### 自动与手工标签分组

- 新建或更新标签后自动按域名前两段整理，例如 `ml.bytedance.net → ml-bytedance`。
- 每个窗口独立建组和计数，不会跨窗口移动或合并标签。
- 标签关闭后会重新计算，数量低于阈值时自动解组并移至右侧。
- 支持 `2–20` 的分组阈值、九色高对比配色、手工整理、撤销和恢复。
- 手工移动过的标签保持原位，同组其他标签仍参与自动整理。

## 安装

### 使用已构建版本

1. 打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择项目中的 `.output/chrome-mv3` 目录。
5. 建议将 Tabloom 固定到 Chrome 工具栏。

### 从源码构建

建议使用 Node.js 22；当前环境的 Node.js 20.17 也已通过完整构建验证，但 npm 会提示 WXT 的官方引擎版本要求。

```bash
npm install
npm run check
```

构建产物位于 `.output/chrome-mv3`。生成可分发 zip：

```bash
npm run zip
```

## 使用

### 任务窗口切换器

1. 按 `⌘⇧K`，或点击工具栏图标后选择“任务窗口切换器”。
2. 侧边栏打开后，使用 `↑` / `↓` 循环选择窗口，按 `Enter` 跳转并自动关闭。
3. 也可点击窗口条目跳转，双击名称可重命名（如“A 模型训练”“B 精度对比”）。
4. 关闭侧边栏后无任何残留 UI。

原 `⌘⇧S` 与 Chrome 原生“网页另存为”冲突，现已改为 `⌘⇧K`。该快捷键同时通过 Chrome 扩展命令和普通网页键盘事件触发，也可在 `chrome://extensions/shortcuts` 中修改。

### 重命名标签

点击工具栏图标，输入标题后保存。也可在网页内容区右键，或使用 `⌘⇧E` 唤起输入框。

扩展安装、升级或重新加载后，会为已经打开的普通网页补充内容脚本；首次操作时若检测到脚本缺失，也会自动注入并重试。补注入过程按标签页去重，避免同一页面注册多个标题处理器。

`chrome://`、Chrome Web Store、扩展页等受限页面不允许内容脚本运行，无法重命名。

### 标签分组

自动整理默认开启。打开标签工作台可调整阈值、立即整理所有窗口、临时关闭自动整理，或手工拖动标签。

截图中书签栏里的已保存标签组由 Chrome 自身管理；扩展公开 API 无法禁止 Chrome 保存或删除这些入口。Tabloom 只维护当前已打开窗口里的实时标签分组。

## 开发

```bash
npm run dev        # 启动 WXT 开发模式
npm run typecheck  # TypeScript 严格检查
npm run lint       # ESLint
npm test           # Vitest
npm run build      # 生产构建
npm run check      # 依次执行全部检查
```

主要目录：

```text
entrypoints/
  background.ts    事件监听与消息编排
  content.ts       标题守护和页面内重命名
  sidepanel/       任务窗口切换器侧边栏
  popup/           工具栏弹窗
src/
  lib/             域名、颜色、存储、窗口元数据和 Chrome 标签服务
  popup/           弹窗 React 组件
  manager/         标签工作台
tests/             领域逻辑和核心交互测试
```

## 隐私

Tabloom 不上传 URL、标题或分组数据，不使用远程脚本。设置保存在本机，窗口名称和标签标题仅保留在当前浏览器会话中。
